# 教程：用 Sora2 快速批量生成字幕文件

Sora2 的第一版聚焦在**字幕生成**，帮助创作者在几分钟内把 Sora 视频转成多语言字幕。

## 1. 环境与素材准备

1. 在项目根目录复制 `.env.example` 为 `.env.local`，填入 Whisper 或 AssemblyAI 的 API Key。
2. 确保本地安装了 Node.js 18+，运行 `npm install && npm run dev`。
3. 准备一段 Sora 导出的 MP4/MOV/WebM 文件，建议时长 30 秒以内以便测试。

## 2. 上传视频并选择语言

打开 `/subtitles` 页面，按照以下步骤操作：

- 上传你的 Sora 视频；
- 选择转写服务（Whisper 推荐高精度，AssemblyAI 推荐快速转写）；
- 勾选需要输出的语言，工具会在后台自动翻译。

工具会在几秒内生成演示字幕片段，并提供 SRT 下载按钮。接入真实 API 后即可返回完整文件。

## 3. 导出并校对字幕

- 下载生成的 `.srt` 或自行转换为 `.vtt`；
- 在剪辑软件中导入字幕文件并预览；
- 若存在专有名词或品牌词，可在界面中手动替换后再次导出。

## 4. 常见问题

> **翻译准确度？**
>
> Whisper/AssemblyAI 可以输出原文，翻译可交给 OpenAI GPT-4o 或其他翻译 API。
>
> **长视频支持？**
>
> 建议拆分为多段上传，或在后端实现文件切片与异步回调。

希望这份教程能帮助你快速完成第一条多语言 Sora 视频。
